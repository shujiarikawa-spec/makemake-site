売上が伸びない原因は？
最初に確認すべき5つのポイント

FIRST, FIND THE STOPPING POINT

「何を強化するか」より先に、
「どこで止まるか」を確認する。

売上が伸びないとき、集客、広告、営業など一つの施策に原因を決めつけると、改善の順番を誤りやすくなります。まずは顧客が知る、理解する、問い合わせる、比較する、購入を続けるまでを見渡してください。

売上が伸びないときに、最初に整理したいこと

「売上が伸びない」は一つの症状であり、原因そのものではありません。新しい見込み客が減っているのか、問い合わせはあるのに商談にならないのか、商談はあるのに受注しないのか。症状が違えば、最初に確認する数字も、打つべき手も変わります。

売上を考えるときは、単純に売上額だけを見るのではなく、顧客が進む過程と、その各段階の数字を並べます。たとえば、新規顧客数、問い合わせ数、商談化率、受注率、受注単価、継続・再購入などです。数字が正確に取れていない場合も、現場の実感と照らして「どこから確認するか」の仮説を置くことはできます。

どこが弱いかを見ずに流入だけを増やすと、失注や離脱の量も増えることがあります。まず「止まる場所」を一つに絞ることが、次の投資判断の出発点です。

売上が伸びない主な5つの原因

以下の5つは、どれか一つだけが問題とは限りません。ただし、同時にすべてを直そうとすると検証できなくなります。自社で最も強い症状から確認してください。

1. 届くべき市場に届いていない

認知やアクセスが少ない場合でも、単に量が足りないとは限りません。誰の、どの場面の、どんな困りごとに応えるのかが曖昧だと、発信、広告、営業リストのすべてが散らばります。まずは既存顧客に共通する課題、選ばれた理由、比較された相手を確認し、届ける相手を具体化します。

確認する問い：「今、最も反応する顧客は誰か」「その人は何に困ったときに探し始めるか」「自社の入口はその場面にあるか」

2. 価値が伝わらず、比較で選ばれない

アクセスや商談の機会があっても、顧客が「自分の課題に関係がある」「他社ではなくここを選ぶ理由がある」と理解できなければ、次の行動には進みません。機能の説明だけで終わっていないか、導入後に何が変わるのかが具体的か、比較の判断材料があるかを見ます。

確認する問い：「顧客の言葉で課題を説明できているか」「導入後の状態が想像できるか」「比較されたときに選ばれる理由が示されているか」

3. 問い合わせ・購入までの導線に摩擦がある

価値を理解しても、次に何をすればよいかが分からない、検討に必要な情報が足りない、行動の負担が大きいと、顧客は離脱します。Webサイトだけでなく、資料、問い合わせ後の案内、担当者からの連絡までを一つの導線として確認します。

確認する問い：「次の行動が一つに定まっているか」「問い合わせ前の不安に答えているか」「問い合わせ後に商談へ進む理由を設計できているか」

4. 商談・提案で期待値がつながっていない

問い合わせ数があっても受注につながらないなら、営業の話し方だけを原因にしないことが大切です。サイトや広告で伝えた内容と、商談で提示する価値、価格、進め方にずれがあると、期待値が切れます。失注理由を「価格が高い」で止めず、比較対象、決裁条件、導入不安まで記録して振り返ります。

確認する問い：「流入時の期待と提案内容はつながっているか」「失注の理由を再現性ある形で記録できているか」「選ばれなかった理由を商品・市場まで戻って見ているか」

5. 商品・価格・収益性の設計が合っていない

売上が増えても、粗利や継続性が低ければ、事業としては苦しくなります。値下げで受注を増やす前に、顧客にとっての価値と価格の関係、提供にかかる負荷、顧客構成への依存を確認します。これはマーケティングだけでは完結しないため、現場・営業・経営の認識を揃える必要があります。

確認する問い：「売上だけでなく、粗利と継続を見ているか」「低採算の受注を増やしていないか」「特定の顧客・チャネルに依存しすぎていないか」

改善の優先順位を決める3ステップ

ステップ1：症状を一文で書く

「売上が伸びない」ではなく、「月間の問い合わせはあるが商談化しない」「受注率は変わらないが新規接点が減った」のように、観測できる事実へ置き換えます。数字があれば期間をそろえ、前年同月・前月など比較の基準も決めます。

ステップ2：原因を一つの仮説にする

施策を先に決めず、「問い合わせ前に必要な比較情報が不足しているかもしれない」「届ける市場と発信テーマがずれているかもしれない」のように仮説にします。仮説なら、確認する数字・顧客の声・ページ・商談記録を決められます。

ステップ3：小さく実行し、次の判断を残す

一度に広告、サイト、営業資料、商品を変えると、何が効いたか分かりません。最も大きい断絶に対して一つの変更を行い、見る指標と期間を決めます。結果が想定と違っても、次に確認するべき場所が明確になれば前進です。

売上が伸びないときに、先にやらない方がよいこと

原因が分からないまま、施策数だけを増やすことです。広告、SEO、SNS、営業のいずれも有効になり得ますが、ボトルネックと合っていなければ改善効果は測れません。特に「アクセスが少ないから広告」「受注しないから値下げ」と即断すると、後から戻しにくい判断になります。

必要なのは、施策を否定することではありません。どの施策を、どの断絶に対して、何を改善するために行うのかを結び直すことです。この考え方を、マケマケでは売上構造として整理しています。

よくある質問

売上が伸びないとき、最初に確認すべきことは何ですか？

施策の量ではなく、顧客がどの段階で止まっているかを確認します。新規接点、価値の伝達、導線、商談、収益性のどこに症状があるかを分けることが出発点です。

広告を増やしても売上が伸びないのはなぜですか？

流入後に価値が伝わらない、問い合わせ導線に摩擦がある、商談時の期待値が切れているなど、広告以外に原因がある可能性があります。

売上改善は何から始めればよいですか？

現状の症状を一文にし、原因の仮説を一つ置きます。その仮説を確かめる数字や記録を決めてから、小さな変更を行います。
