BEFORE THE CONSULTATION

広告の期待を、
LPで受け止められなかった。

C社は特定職種の人材紹介を行っています。広告では「すぐに紹介できる」を前面に出している一方、LPでは会社紹介やサービス範囲の説明が先行していました。広告で期待を持った採用担当者が、LP上で自社の採用条件に合うか判断できず、フォーム前に離脱する状態でした。

OBSERVED CONDITION

広告からの流入が、相談開始までつながりにくい。

02
