MODEL CASE

D社 / ITコンサル年商5億円規模の想定

属人的な営業から脱却。
ホワイトペーパーを起点とした商談導線の構築。

課題の見立てから導線の再設計までを紹介するモデルケースです。数値はKPIを確認するための設計例です。

01.相談前の状態

D社は、業務システムの企画・導入支援を提供しています。代表や一部の営業担当者の紹介に依存しており、初回商談で何を提供できるかを説明する負荷が高い状態です。サイトにも支援メニューはありますが、まだ相談する段階ではない担当者が理解を深める入口がありません。

02.ボトルネックの見立て

検討段階の違う人を、同じ「お問い合わせ」へ送っている

  • 導入を急ぐ人と、課題を整理したい人が同じページに着地する。
  • 営業資料が口頭説明に閉じ、サイト上で判断材料になっていない。
  • ダウンロード後に、次に読む内容や相談する理由が設計されていない。

03.再設計の考え方

顧客が社内で検討を進めるためのホワイトペーパーを起点にします。テーマはサービス紹介ではなく、たとえば「基幹システム刷新前に決める論点」のように、検討初期の判断を助けるものにします。ダウンロード後は関連する支援ページ、個別相談、既存の考え方を段階的につなぎ、営業が改めてゼロから説明しなくても前提を共有できる導線をつくります。

04.変化を測る場合のKPI例

カードの「月3件→15件」は数値例です。実務では、資料ダウンロード数よりも、資料からサービスページへ進んだ割合、相談への移行率、商談で課題が具体化している割合を確認します。資料を配ること自体ではなく、検討と営業がつながることを評価します。
