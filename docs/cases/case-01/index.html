MODEL CASE

A社 / BtoB SaaS年商3億円規模の想定

市場定義をズラし、比較の土俵を変える。
CPAを見直すための構造設計。

課題の見立てから導線の再設計までを紹介するモデルケースです。

01.相談前の状態

A社は、勤怠・労務領域のクラウドサービスを提供しています。広告では大手と同じ広いカテゴリ語を使い、LPでは「DX」「効率化」と説明していました。そのため、サービスの違いが伝わる前に価格や知名度で比較され、広告費を増やしても相談の質が安定しない状態を想定しています。

02.ボトルネックの見立て

広告運用ではなく、市場定義と価値表現の断絶

  • 人事部向けの大きな市場で、大手と同じ言葉を使っている。
  • 兼任の総務担当者が抱える不安と、サイトの訴求が接続していない。
  • 広告の約束とLPで受け取る印象に差がある。

03.再設計の考え方

まず既存顧客の導入理由を整理し、専任担当者がいない小規模組織が「月末の手作業を減らしたい」「担当者交代でも回る状態にしたい」と考える場面に焦点を置きます。訴求、比較材料、デモ依頼までをこの状況に合わせ、広告とLPが同じ約束を伝えるように組み直します。

市場

競合と同じ広い市場から離れる

価値

兼任者の判断材料で伝える

導線

広告とLPの約束を統一する

04.改善の見方

実務では、広告クリック後のサービス理解、デモ予約開始、商談化までの各段階を確認します。CPAだけを下げるのではなく、受注につながる相談が増えているかを併せて判断します。
