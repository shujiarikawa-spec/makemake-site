BTOB / INQUIRY DIAGNOSIS

BtoBの問い合わせを増やすには？
施策の前に確認する4つの断絶

SEO、広告、フォーム改善を始める前に、どこで見込み顧客が止まっているかを見ます。問い合わせの量だけを増やすのではなく、商談につながる改善の順番を決めるための診断ガイドです。

DON'T ADD TACTICS YET

問い合わせを増やす前に、
止まる場所を一つに絞る。

BtoBでは、問い合わせはゴールではなく商談の入口です。流入だけ、フォームだけを直しても、対象顧客・伝える価値・次の行動・営業の受け渡しがつながらなければ、売上につながる問い合わせは増えません。

問い合わせを増やす施策を、先に選ばない

「問い合わせを増やしたい」とき、SEO、広告、SNS、CTA、フォームなどの施策から考え始めると、原因と打ち手がずれやすくなります。たとえばアクセスが少ないのにフォームだけを直しても、検討度の低い問い合わせばかりを増やしても、期待した商談にはつながりません。

最初に必要なのは、見込み顧客がどこで止まり、何を判断できていないのかを分けることです。問い合わせ数、流入数、フォーム送信数だけで結論を出さず、顧客が進む過程と営業へ渡る過程を続けて確認します。

マケマケの「4つの断絶診断」

問い合わせの停滞を、次の4つに分けて見ます。これは施策の一覧ではなく、確認の順番を決めるための診断枠です。

01 / REACH

届いていない

対象顧客が検索・紹介・広告などでサイトに到達していない、または流入元と提供価値が合っていない状態。

02 / RELEVANCE

自分ごとにならない

訪問はあるが、誰向けで何を解決するのか、比較時に選ぶ理由が伝わらず離脱する状態。

03 / ACTION

次に進めない

検討に必要な情報、問い合わせ後の見通し、CTAやフォームの使いやすさが不足して行動が止まる状態。

04 / HANDOFF

商談につながらない

問い合わせと営業の期待値、対象条件、初回対応がつながらず、商談・受注へ進まない状態。

最初に並べるべき、4種類の事実

改善の前に、まず直近の同じ期間で次の事実を並べます。数字が十分に取れていない場合は、現場の記録や商談メモを使い、推測と事実を分けてください。

1. 流入：誰が、どこから来ているか

自然検索、広告、紹介、直接流入などの入口ごとに、サービスページへ来ているかを見ます。アクセスがあっても、対象外のテーマからの流入であれば、問い合わせに結びつかないことがあります。

2. 理解：サービスページで何を見ているか

どのページから離脱しているか、サービスや事例に進んでいるか、よく読まれるテーマは何かを確認します。顧客が探している課題と、サイトが最初に説明している内容が合っているかを見ます。

3. 行動：フォームの前後で何が起きているか

問い合わせページの閲覧、フォームの開始、送信完了を分けて確認します。送信前に止まるなら、入力負担だけでなく「送信すると何が起きるのか」という不安も仮説に含めます。

4. 商談：問い合わせの後に何が起きているか

問い合わせ件数だけではなく、商談化、失注、受注までを流入元・相談内容・対象顧客ごとに振り返ります。営業が受け取りたい相談と、マーケティングが集めている相談にずれがないかを確認します。

4つの断絶ごとに、最初の一手を決める

届いていないなら、入口の前提を確認する

増やすべきなのは単なるアクセスではなく、対象顧客との接点です。既存顧客が検討を始めたときの検索語、紹介元、困りごとを集め、どの入口を増やすべきかを決めます。BtoBポジショニングで整理した「誰のどの課題か」が曖昧なら、広告やコンテンツの前にそこから戻ります。

自分ごとにならないなら、価値の伝え方を確認する

「何ができるか」だけでなく、誰のどんな場面で、何が変わるのかを最初に示します。機能比較より前に、顧客が自分の課題だと判断できる言葉、比較時に見る根拠、導入後の進め方を揃えます。

次に進めないなら、検討の摩擦を一つずつ外す

CTAを増やすことが答えとは限りません。料金、対応範囲、導入の流れ、相談後の連絡など、顧客が迷っている点を仮説にします。最も多く見られるページと問い合わせ導線をつなぎ、次の行動を一つに絞ります。

商談につながらないなら、受け渡しを設計する

問い合わせの内容、返信までの流れ、初回商談で聞くこと、対象外と判断する基準を営業と共有します。問い合わせを増やす施策と、商談の質を高める設計は別に考える必要があります。

30分で行う問い合わせ構造チェック

A. 直近の問い合わせを5件並べる

流入元、相談内容、商談化の有無、失注理由を、分かる範囲で記録する。

B. サービスページから送信までの動きを確認する

どのページで理解が止まり、問い合わせ前に何を確かめたくなるのかを書き出す。

C. 4つの断絶から最も強い仮説を一つ選ぶ

「届いていない」「自分ごとにならない」「次に進めない」「商談につながらない」を同時に直そうとしない。

D. 変更点と見る指標を一つに絞る

たとえばサービスページの導入文を変えるなら、ページ遷移、問い合わせ、商談内容の変化を記録する。

問い合わせ数だけをKPIにすると起きること

問い合わせ数は重要ですが、それだけを増やすと、対象外の相談や、比較だけを目的とする相談を増やすことがあります。これは問い合わせ自体が悪いということではなく、どの相談が事業にとって意味のある商談へ進むのかを決めずに量だけを追うと、次の判断が難しくなるということです。

まずは問い合わせ、商談、受注のつながりを確かめます。売上全体のどこで止まるかを広く整理したい場合は、売上が伸びない原因の記事もあわせて確認してください。

よくある質問

BtoBの問い合わせを増やすには、最初に何を確認すべきですか？

流入、訴求、導線、商談のどこで顧客が止まっているかを数値と顧客の行動から確認します。問い合わせ数だけでなく、流入元、サービスページ、フォーム到達・送信、商談化までを分けて見ます。

アクセスがあるのに問い合わせが増えないのはなぜですか？

訪問者とサービスの対象がずれている、課題との関係や選ばれる理由が伝わらない、問い合わせ前の不安が解消されない、フォームや問い合わせ後の流れに摩擦があるなどの可能性があります。

問い合わせ数と商談数は同じように考えてよいですか？

同じではありません。問い合わせの量を増やしても、対象顧客や相談内容が事業と合っていなければ商談・受注にはつながりません。対応の流れも確認します。
