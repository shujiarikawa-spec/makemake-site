MODEL CASE

C社 / 人材紹介業年商2.5億円規模の想定

断絶していた広告とLPの導線を接続。
CVRを見直す90日間。

課題の見立てから導線の再設計までを紹介するモデルケースです。数値はKPIを確認するための設計例です。

01.相談前の状態

C社は、特定職種の人材紹介を行っています。広告では「すぐに紹介できる」を前面に出している一方、LPでは会社紹介やサービス範囲の説明が先行していました。広告で期待を持った採用担当者が、LP上で自社の採用条件に合うか判断できず、フォーム前に離脱する状態を想定します。

02.ボトルネックの見立て

クリックの理由と、LPで得られる答えが一致していない

  • 広告は採用の緊急性を示すが、LPでは対象職種や紹介の進め方が後ろにある。
  • 相談前に知りたい費用感・対応地域・紹介可能な条件が見つけにくい。
  • フォームが「資料請求」と「採用相談」を同じ入口にしている。

03.90日で進める再設計

最初の30日で検索語・広告文・流入ページを整理し、次の30日でLPの冒頭を広告別の課題に合わせます。最後の30日では、対象職種・採用期限・相談目的を選べるフォームへ変更し、問い合わせ後の商談化まで確認します。CVRだけではなく、採用要件が明確な相談の割合を重視します。

04.変化を測る場合のKPI例

カードのCVR「0.8%→3.0%」は数値例です。実務では、広告別のLP到達率、フォーム開始率、送信率、商談化率を分け、どの断絶を直した結果なのかを判断します。数字だけを上げるためにフォームを短くするのではなく、相談の質を損なわないことが前提です。
