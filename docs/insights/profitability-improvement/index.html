DON'T OPTIMIZE REVENUE ALONE

売上を増やす前に、
利益が薄くなる場所を分ける。

広告費、原価、値引き、運用工数、継続率は別々の数字ではありません。どの顧客に、どの商品を、どの経路で届け、どこまで継続してもらうかがつながって、収益性が決まります。

売上は、利益の代わりにならない

売上が伸びているのに利益が残らないとき、「もっと売上を増やせば解決する」と考えると、薄い利益をさらに大きくすることがあります。売上は取引の大きさであり、利益はその取引を続けられるかを示すものです。両方を見る必要があります。

収益性は、CPAだけでも、原価率だけでも説明できません。どの顧客を獲得し、どれだけのコストで届け、どの条件で受注し、その後どれだけ続くかを、一つの構造として確認します。

利益が薄くなる5つの確認点

01 / ACQUISITION

獲得コストが重い

広告費や営業工数に対して、獲得後の粗利や継続から回収できる見通しが持てない状態。

02 / GROSS PROFIT

提供コストが読めていない

原価、外注費、運用時間、サポート負荷が、商品別・顧客別に把握されていない状態。

03 / PRICE

値引きが前提になっている

受注のたびに値引きが必要になり、提供する価値と受け取る対価の関係が崩れている状態。

04 / ORDER VALUE

客単価の設計が弱い

顧客の課題に対して必要な範囲が商品化されず、低い単価の入口だけで終わる状態。

05 / CONTINUITY

継続・リピートにつながらない

初回受注の後に成果の確認、次の課題、継続する理由が設計されず、獲得コストを初回だけで回収しようとしている状態。

最初に並べるべき数字

全社平均だけで結論を出さず、商品・顧客・流入元など判断に使える単位に分けます。売上と粗利、獲得にかかったコスト、値引きの理由、初回受注後の継続を同じ期間で並べ、利益が残る取引と残らない取引の違いを見ます。

見直す順番を間違えない

獲得コストが重いなら、広告費だけを見ない

CPAが高いとき、まず確認するのは「誰を獲得しているか」です。対象外の流入を集めていないか、訴求と商品がつながっているか、商談・受注まで進む顧客を獲得できているかを見ます。

提供コストが重いなら、商品ごとの境界を決める

追加の作業やサポートが常態化しているなら、「どこまでを商品に含めるか」を明確にします。顧客満足と無制限の対応を同じものにせず、提供する価値、対応範囲、追加費用の条件を揃えます。

値引きが多いなら、価格の前に価値の伝わり方を見る

誰のどんな課題を解決し、なぜその方法なのか、他の選択肢と何が違うのかが伝わらなければ、商談は価格比較に寄りやすくなります。

継続しないなら、初回受注の先を設計する

受注時点で、導入後に何を確認するか、次にどんな課題があり得るか、継続の判断をいつ行うかを共有します。顧客が次の価値を判断できる状態をつくります。

30分で行う収益構造チェック

A. 直近の取引を商品・顧客ごとに並べる

売上、提供コスト、獲得経路、値引き、継続の有無を、分かる範囲で記録する。

B. 利益が残る取引と残らない取引を分ける

平均値だけではなく、どの条件で違いが生まれるかを見る。

C. 最も大きい仮説を一つ選ぶ

獲得・提供コスト・価格・客単価・継続を同時に直そうとしない。

利益を、経理だけの数字にしない

利益は、月末に結果として見るだけの数字ではありません。市場、価値、導線、商談で行った判断が、最終的に収益性へ現れます。売上を増やす施策と、利益を残す設計は切り離さずに見ることが必要です。

よくある質問

売上が増えているのに利益が残らないのはなぜですか？

集客コスト、原価、値引き、客単価、継続・リピートのどこか、または複数で利益が薄くなっている可能性があります。

CPAが高いときは広告を止めるべきですか？

CPAだけで判断せず、獲得した顧客の粗利や継続も含め、顧客あたりで回収できる構造になっているかを見ます。
